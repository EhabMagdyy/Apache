Projects

STM32 FOTA

This project implements a Firmware Over-The-Air update mechanism for STM32F4 microcontrollers using a custom bootloader. The STM32 communicates with a host via ESP32 to receive commands from a Node-RED Dashboard.

RC Car

A remote controlled and obstacle avoidance car using STM32 and ESP32 as a Bluetooth module. It receives direction commands and speed changes from a mobile phone via Bluetooth and relays them to the STM32 via UART.
